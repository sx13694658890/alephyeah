## 四、快速查找指南

**想找特定场景的图片提示词：**
1. 查 **一.1** → 按场景名定位（海边/居家/时尚/户外/庭院）
2. 点击笔记标题进入查看完整 prompt

**想找网页开发提示词：**
1. 查 **二** → 按品牌名定位
2. 每个笔记包含完整实现代码 + CSS

**想找共用风格/技术：**
1. 查 **三 标签云** → 按标签筛选
2. 例如点 `85mm` 可找到所有 85mm 镜头设定的提示词

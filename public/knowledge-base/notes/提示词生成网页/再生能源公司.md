使用 React、Vite、TypeScript、Tailwind CSS、Framer Motion 和 Lucide React 图标，为一家可再生能源公司构建一个全屏英雄登陆页面。使用 Google Fonts 中的 Inter 字体（字重 300-900）。页面背景色为 `[#F7F7F7](https://x.com/hashtag/F7F7F7?src=hashtag_click)`。 ## 依赖项 ``` react, react-dom, framer-motion, lucide-react, clsx, tailwind-merge ``` ## 全局 CSS (`index.css`) 从 Google Fonts 导入 Inter：`[https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700;800;900&display=swap](https://t.co/EWb9NGszke)` 在 body 上设置 `font-family: 'Inter', sans-serif`。 添加一个 `.liquid-glass` 实用类： - `background: rgba(255, 255, 255, 0.01)` 结合 `background-blend-mode: luminosity` - `backdrop-filter: blur(4px)` 和 `-webkit-backdrop-filter: blur(4px)` - 无边框，`box-shadow: inset 0 1px 1px rgba(255, 255, 255, 0.1)`，`position: relative`，`overflow: hidden` - 一个 `::before` 伪元素，带有 `position: absolute; inset: 0; border-radius: inherit; padding: 1.4px`，以及一个垂直线性渐变的白色的不同不透明度（0%/100% 处为 `rgba(255,255,255,0.45)`，20%/80% 处为 `rgba(255,255,255,0.15)`，40%/60% 处为 `rgba(255,255,255,0)`），使用 `-webkit-mask-composite: xor` / `mask-composite: exclude` 蒙版来创建玻璃边框效果。 添加一个 `.tracking-tight-custom` 实用类，带有 `letter-spacing: -0.06em`。 添加一个 `

[@keyframes](https://x.com/keyframes)

scroll` 动画：`0% { transform: translateX(0) }` 到 `100% { transform: translateX(-50%) }`。 ## 实用工具：`cn()` 辅助函数 一个结合 `clsx` 和 `tailwind-merge` 的小型实用工具： ```ts import { type ClassValue, clsx } from 'clsx'; import { twMerge } from 'tailwind-merge'; export function cn(...inputs: ClassValue[]) { return twMerge(clsx(inputs)); } ``` ## 组件：`<StaggeredFade>` Props：`text: string`，`className?: string`，`style?: React.CSSProperties`。 渲染一个 `<motion.h1>`，将 `text` 分割成单个字符。每个字符是一个 `<motion.span>`，带有交错的淡入动画：每个字母延迟 `i * 0.03` 秒，持续时间 `0.3s`，从 `opacity: 0` 过渡到 `opacity: 1`。使用 `useInView` 并设置 `once: true` 来在滚动进入视口时触发。基础 className 使用 `cn()` 辅助函数合并 `'text-xl text-center sm:text-4xl font-bold tracking-tighter md:text-6xl md:leading-[4rem]'` 与传入的 `className`。 ## 组件：`<FadeDown>` Props：`children: React.ReactNode`，`delay?: number`（默认 `0`），`className?: string`。 一个 `<motion.div>` 包装器，从 `{ opacity: 0, y: -20 }` 动画到 `{ opacity: 1, y: 0 }`，持续 `0.6s`，带有指定的延迟。通过 `useInView({ once: true })` 在进入视口时触发一次。 ## 组件：`<BoomerangVideoBg>` 这是创建正向/反向回旋镖循环效果的关键背景视频组件。 **视频 URL：** `[https://d8j0ntlcm91z4.cloudfront.net/user_38xzZboKViGWJOttwIXH07lWA1P/hf_20260527_061033_0f369854-8849-4214-8787-9181479c8121.mp4](https://t.co/9Z2t7Wgz3L)` **工作原理：** 1. 渲染一个 `<video>` 元素（autoPlay、muted、playsInline、crossOrigin="anonymous"），播放一次（不循环）。 2. 在视频播放时，使用 `requestVideoFrameCallback`（对于不支持的浏览器，使用 60fps 的 `setInterval` 作为后备）将每一帧捕获到离屏 `<canvas>` 元素中。每个捕获的帧缩放到最大宽度 960px，同时保持纵横比。 3. 当视频 `ended` 事件触发时，将 `ready` 状态设置为 `true`。 4. 一旦准备就绪，隐藏 `<video>` 并显示可见的 `<canvas>`。一个 `requestAnimationFrame` 循环以 30fps 回放捕获的帧，形成回旋镖模式：正向播放所有帧，然后反向回到开始，无限重复。 5. 外部包装 div 的类为：`absolute inset-0 w-full h-full`。 6. `<video>` 和 `<canvas>` 都有类：`w-full h-full object-cover`。 7. 通过 `style={{ display: ready ? 'none' : 'block' }}` 在视频上切换可见性，并在 canvas 上使用相反的逻辑。 ## 主布局 (`App.tsx`) 根元素为 `<div className="h-screen flex flex-col bg-[[#F7F7F7](https://x.com/hashtag/F7F7F7?src=hashtag_click)] relative overflow-hidden">`。 ### 视频背景 `<BoomerangVideoBg>` 放置在一个容器中：`<div className="fixed inset-0 z-0" style={{ top: 200 }}>`。这将视频从视口顶部向下推 200px，以便它位于英雄区域下部后面。 ### 导航栏 一个 `<nav>`，类为 `flex items-center justify-between px-4 md:px-8 py-4 md:py-6 relative z-10`。 **左侧：** - 一个徽标图像：`<img src="/image.png" alt="LGPSM" className="h-6 md:h-7" />`（用户自己的徽标 PNG） - 一个语言选择器：`<Globe>` 图标（lucide-react，`w-4 h-4`）+ "En" 文本，`text-sm text-black` **中心（在移动端隐藏，`hidden lg:flex items-center gap-8`）：** - 导航链接："Renewables"、"Strategies"、"Photovoltaic"、"Wind Systems"、"Packages" - 每个链接：`text-sm text-gray-700 hover:text-gray-900` **右侧：** - "Sign In" 链接（在移动端隐藏 `hidden sm:block`）：`text-sm text-gray-700 hover:text-gray-900 border border-black/20 px-4 md:px-6 py-2 md:py-2.5 rounded-full transition-colors` - "Clean Energy" 按钮：`px-4 md:px-6 py-2 md:py-2.5 bg-black text-white text-sm rounded-full hover:bg-gray-900 transition-colors` ### 英雄内容 包装器：`<div className="flex-1 flex flex-col items-center px-4 md:px-8 relative pt-4 md:pt-8">`，内部有一个 `<div className="relative z-10 flex flex-col items-center">`。 **徽章药丸**（顶部，居中）： - 类：`mb-3 px-3 md:px-4 py-1.5 md:py-2 border border-black/20 rounded-full flex items-center gap-1.5 md:gap-2 text-xs md:text-sm` - 内容：太阳表情符号、箭头、地球仪表情符号、文本 "Delivering power innovate"（在移动端隐藏，在小屏幕上缩短为 "Power innovate"），箭头、植物表情符号 **主标题**（使用 `<StaggeredFade>`）： - 文本：`"Renewable Power For Tomorrow, Infinite Clean Solutions"` - 类：`text-3xl sm:text-4xl md:text-5xl lg:text-6xl leading-tight font-normal text-center max-w-5xl mb-3 md:mb-4 px-4` - 颜色：`[#31463B](https://x.com/hashtag/31463B?src=hashtag_click)`（深绿色），通过内联样式 **副标题**（包裹在 `<FadeDown delay={0.5}>` 中）： - `<p>` 类：`text-center text-gray-600 max-w-3xl mb-4 md:mb-5 text-sm md:text-base lg:text-lg px-4` - 文本：`"Sustainable Energy Platform. Engineering, deploying, and servicing solar arrays for homes, businesses, and large-scale operations worldwide."` **CTA 按钮**（包裹在 `<FadeDown delay={0.7}>` 中）： - 包装器类：`flex flex-col sm:flex-row items-center gap-3 md:gap-4 px-4` -
